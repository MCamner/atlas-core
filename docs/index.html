Atlas Core

Standalone loop engine for routed, evaluated, retryable AI-assisted work.

Atlas Core is a bounded task loop. It observes context, chooses a route, plans the next action, executes, evaluates the result, retries when that helps, and stops when the answer is good enough.

observe → route → plan → execute → evaluate → retry / replan → finalize

It is intentionally separate from the MQ stack. MQ, GitHub, Obsidian, ChatGPT Skills, and local memory plug in as adapters rather than becoming the core.

Quick start

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m unittest discover -s tests

Routes

Routes are data, not prompt prose. Seven ship in routes/routes.json:

  • repo_review — observe, summarize, find gaps, prioritize
  • architecture_decision — requirements, design, risk, options
  • root_cause — symptoms vs causes, causal chain, actions
  • decision_tradeoff — context, options, trade-offs, recommendation
  • learning — plain explanation, common confusion, example
  • prompt_improvement — diagnose, failure modes, rewrite, test cases
  • general — understand, answer, next step
Atlas Core is read-only by default and ships no LLM provider. Model execution is an adapter you add; see the safety model in the repository.
